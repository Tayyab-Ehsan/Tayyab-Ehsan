## 🚀 About Me  
I am a **Python Data Scientist** specializing in machine learning, computer vision, and 3D spatial data.  
I develop deep learning models for **point cloud segmentation** and geometric data understanding using **PyTorch** and graph-based refinement techniques.  
🔎 I love solving complex problems using data and am passionate about **emerging technologies** in computer vision and AI!  
⚡ Currently building tools that improve segmentation accuracy on unstructured 3D data.
---
## 🔭 Current Projects  
### 🔹 Point Cloud Segmentation Refinement  
- PointNet-style point cloud segmentation with graph-based refinement, built in Python.
- Applying deep learning to raw 3D point cloud data for semantic segmentation.
- Using graph-based post-processing to refine noisy model predictions and improve boundary precision.
